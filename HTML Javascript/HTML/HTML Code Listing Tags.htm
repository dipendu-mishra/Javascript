LISTING TAGS

LISTING TAGS
The listing tags set out the content in prescribed ways, and the different tags are aimed at data of a certain type.
ORDERED LIST (ol)
Produces a listing rendered with a leading number, roman number, letter, etc. depending on the TYPE specified.
The default (unspecified) type is numbers (1).
The listing can be started from a specified letter etc. which can be useful where complex content is involved.
Type Letters (A) Letters (a) Roman (I) Roman (i) Numbers (1)
first A a I i 1
second B b II ii 2
third C c III iii 3
fourth D d IV iv 4
Syntax
<OL type=A, a, I, i, 1 start=any character(s) in the type range (eg. E, g, II, ix, 12) >
<li> first line ...</li>
<li> second line ...</li>
etc
</OL>
UNORDERED LIST (ul)
Produces a listing with bullet points.
The default (unspecified) bullets are:
  • Level One -disc
    • Level Two - circle
      • Levels thereafter - square
Syntax
<UL type=circle, disc, square >
<li> first line ...</li>
<li> second line ...</li>
etc
</UL>
DESIGNER BULLET LIST
Selected graphics can be employed as bullets for the list, using CSS styling.

DEFINITION LIST (dl)
Produces a rendering with Headings and indented Items
    Definition Title-1
    Defintion Data-1 indented
    Definition Title-2
    Definition Data-2 indented
Syntax
<DL>
<DT> first heading ... </DT>
<DD> first item ... </DD>
etc
</DL>
